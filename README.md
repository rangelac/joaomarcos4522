# joaomarcos4522.com.br

Site institucional da campanha de João Marcos Luz, candidato a Deputado Federal pelo Acre.

## Publicação na Hostinger via Git

1. No hPanel, abra **Websites → Gerenciar → Git**.
2. Conecte o repositório `https://github.com/rangelac/joaomarcos4522`.
3. Selecione a branch `main` e o diretório de destino do domínio.
4. Como o site é estático, não há comando de build: o diretório publicado deve conter `index.html`, `styles.css`, `script.js` e `assets/`.
5. Ative o deploy automático para atualizar o site a cada push na branch `main`.

Antes de publicar, revise os dados legais, contatos e textos de campanha com a equipe responsável.
